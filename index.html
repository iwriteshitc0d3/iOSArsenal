MASVS Categories

Jailbreaking a Test Device

Several playbooks above assume a jailbroken test device (Keychain dumping, filesystem access, ptrace/anti-debug testing). Jailbreak availability shifts constantly as Apple patches exploits — always verify current compatibility for your exact device and iOS build before relying on any of these, and only download tools from the projects' own official sites (lookalike sites bundling malware are common).

Jailbreak Detection Bypass

Once the device is jailbroken, most apps will actively try to detect and block that. These four approaches escalate in effort — try the one-command tools first, and fall back to custom hooking or static patching for apps with less common checks.

SSL / Certificate Pinning Bypass

Pinning is usually the single control standing between a proxy setup and full traffic visibility. The right technique depends on what the app pins with — a known library (TrustKit, Alamofire, AFNetworking) is often a one-liner; custom validation logic needs a targeted hook.

📚 API Specification Reference

Available endpoints exposed by the Node.js Express router engine:

GET /api/stats
Returns aggregate counts, review progress, and category/severity breakdown distributions.
GET /api/categories
Lists all 8 MASVS categories with their metadata, icons, and dynamic count of checks.
GET /api/categories/:key
Returns category details and all associated vulnerability playbooks.
GET /api/playbooks
Search and filter playbooks. Supported query params: ?cat=crypto, ?sev=critical, ?q=frida, ?tool=objection, ?sort=sev.
GET /api/playbooks/:id
Returns the full playbook object including all multi-technique exploitation PoC commands, rationale, tools, and mitigations.
GET /api/modules/:type
Access reference modules: jailbreaks, jbdetect (detection bypass), and sslpin (certificate pinning bypass).
GET POST DELETE /api/reviewed
Persistent tracking state for reviewed checklist items. GET to retrieve, POST to update an item, DELETE to reset.
GET /api/export
Exports the entire knowledgebase (categories, 61 playbooks, and 3 bypass modules) in clean JSON format.

📖 About this checklist

iOSArsenal is a single, dependable place to turn to when assessing iOS applications. Whether you're mid-engagement and need the exact PoC steps for a WKWebView bridge, refreshing your memory on Keychain accessibility flags, or handing a developer a clear remediation, it's meant to be the reference you keep open in the other tab.

The guidance here is drawn from the OWASP Mobile Application Security project — MASVS, MASTG, MASWE, and the MAS Checklists — plus standard iOS platform documentation (Keychain Services, App Transport Security, LocalAuthentication, WKWebView). MASWE is a platform-agnostic catalogue shared by Android and iOS; these 61 playbooks map the entries that manifest through iOS-specific APIs and mechanisms.

This is an open, community-maintained project. Found a stale command, a broken bypass, or want to add a newly disclosed vulnerability class? See CONTRIBUTING.md — every playbook lives in a single data.js file, so adding one is usually a single well-formed object in a pull request.

Use with care. MASTG/MASWE reference IDs shown here are approximate pointers, not a guaranteed 1:1 mapping — the OWASP MAS project is under active development and IDs shift between revisions, so cross-check against the live docs before citing them in a report. Tooling and iOS versions move quickly too: an entitlement gets deprecated, an API changes behaviour under App Transport Security, or a jailbreak-detection bypass needs adjusting for the newest iOS release. Treat every PoC as a starting point, not gospel.

Authorised use only. Everything here is for testing applications you own or are explicitly authorised to assess — a signed engagement, an in-scope bug-bounty program, or your own lab. Never use these techniques against apps or systems you don't have written permission to test. Stay within scope and follow responsible disclosure.
